Work

I've been at Amber, a global student-housing marketplace, since May 2024. Most of what I've built there is the plumbing a sales team stands on.

Prism lead memory

6.2 million communications across 177 thousand leads, from WhatsApp, calls, emails, SMS and notes, folded into one profile an agent can read in 30 seconds. Postgres changes stream through Kinesis into DocumentDB, a map-reduce LLM pipeline keeps profiles fresh with debounced refresh workers, and the CRM reads them over a Hono API. I built the screens too: facts, story, risks, next steps, and a timeline with evidence links.

Sales audits an LLM judge that must quote its sources

Every call and chat is scored against a versioned, hash-locked 17-parameter rubric, and the model has to cite the transcript. All the arithmetic stays in TypeScript, so it can't invent a grade; missing data is excluded and its weight redistributed rather than marked as failure. Rolled up into per-salesperson report cards, so managers get continuous feedback instead of spot checks.

Lead routing DCM

The engine that decides who gets each incoming lead: conversion-weighted scoring with Bayesian smoothing, bucket rules, region filters, round-robin modes, and workers that catch misrouted or stale leads and send them back.

Automations and bulk WhatsApp

An open-source workflow builder extended into the CRM's production automation platform, with event triggers, database-driven cron, custom TypeScript steps and email. And a self-serve bulk WhatsApp tool: upload a CSV, preview, send, read delivery reports. Sales no longer files a ticket for a campaign.

The CRM itself and some side things

Set up the new React 19 + Vite + TanStack app and rebuilt inventory onboarding, bulk commissions and supply dashboards on it. Helped move inventory from a fixed three-level to a dynamic n-level hierarchy with OpenSearch search. Locked down PII endpoints with role-based access, rate limits and encrypted identifiers. A pipeline that spots blurred listing photos (about 1 in 60) and restores them with image models. On the side: Sonic and an image editor.
