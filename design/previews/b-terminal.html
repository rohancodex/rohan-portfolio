cat work/*.md

prism.md lead memory

6.2M+ communications across 177K+ leads (WhatsApp, calls, emails, SMS, notes) turned into a single profile an agent reads in 30 seconds. Kinesis CDC streams Postgres changes into DocumentDB; a map-reduce LLM pipeline with debounced refresh workers keeps profiles current; the CRM reads them over a token-authenticated Node/Hono API.

The screens on top, in React: facts, story, risks, suggested next steps, coaching notes, evidence links, and a paginated timeline of every communication.

audits.md an LLM judge that has to show its work

Every call and chat transcript is scored against a versioned, hash-locked 17-parameter rubric. The model must quote the transcript as evidence; all arithmetic stays in TypeScript, so it can never invent a grade. Missing data is excluded and its weight redistributed, not scored as failure. Rolled up into per-salesperson report cards with an LLM-written narrative of each person's patterns.

dcm.md lead distribution

Routes every incoming lead to the right salesperson: conversion-weighted agent scoring with Bayesian smoothing, rule-based bucket matching, per-agent region filters, round-robin modes, and workers that catch and reassign misrouted or stale leads.

automations.md so sales never needs an engineer

An open-source AI workflow builder extended into the CRM's production automation platform (Next.js, React Flow, SQS): event-driven execution, database-driven cron, custom TypeScript code steps, email. Plus self-serve bulk WhatsApp: upload a CSV, preview, send, read per-message delivery reports.

crm.md re-platform, inventory, security

Set up the React 19 + Vite + TanStack CRM and rebuilt inventory onboarding, bulk commissions and supply dashboards on it. Migration from a fixed 3-level to a dynamic n-level inventory hierarchy with OpenSearch-backed search. Role-based ACLs, per-user rate limits with Slack alerts, encrypted identifiers on PII endpoints. A Ruby memory-fragmentation fix rolled out to every service.

side/ sonic, image-editor

sonic, a React + Supabase app, and an image editor in Next.js with Framer Motion. A listing-photo pipeline at work that catches blurred uploads (about 1 in 60) and restores them with OpenAI image models.
