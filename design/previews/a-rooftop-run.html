What I build

Prism lead memory

6.2M+ communications across 177K+ leads, from WhatsApp, calls, email, SMS and notes, folded into one profile an agent reads in 30 seconds. Kinesis CDC out of Postgres into DocumentDB, a map-reduce LLM pipeline with debounced refresh workers, a token-authenticated Hono API, and the React screens on top: facts, story, risks, next steps, evidence links.

Sales audits an LLM judge that must cite its sources

Every call and chat is scored against a versioned, hash-locked 17-parameter rubric, and the model has to quote the transcript as evidence. All the arithmetic stays in TypeScript, so it can never invent a grade. Rolled up into per-salesperson report cards that replaced a team's manual call reviews.

DCM lead distribution

The engine behind every incoming lead: conversion-weighted agent scoring with Bayesian smoothing, bucket rules, per-agent region filters, round-robin modes, and workers that catch and reassign stale or misrouted leads.

Automations the platform teams use to skip the engineer

An open-source workflow builder extended into the CRM's production automation platform: event triggers, database-driven cron, custom TypeScript steps, email. Plus self-serve bulk WhatsApp with per-message delivery reports, so a campaign send no longer needs a ticket.

And the rest CRM re-platform, image quality, security

Set up the new React 19 + Vite + TanStack CRM and rebuilt inventory onboarding, bulk commissions and supply dashboards on it. A pipeline that catches blurred listing photos (about 1 in 60) and restores them with image models. Role-based ACLs, per-user rate limits and encrypted identifiers on PII endpoints.
